# سیستم مرتبه اول با فیدبک و کنترل‌کننده تناسبی (P)

این مخزن یک پروژه آموزشی برای **آزمایشگاه کنترل** است. در آن رفتار یک فرآیند مرتبه اول با فیدبک منفی واحد بررسی می‌شود و اثر تغییر بهره تناسبی بر سرعت پاسخ، دقت تعقیب مرجع و سیگنال کنترلی تحلیل می‌گردد.

## کاربرد آزمایش
این شبیه‌سازی نشان می‌دهد افزایش بهره تناسبی معمولاً پاسخ را سریع‌تر می‌کند و خطای ماندگار ورودی پله را کاهش می‌دهد. خروجی‌ها برای مقایسه تحلیلی و شبیه‌سازی با نتایج آزمایشگاهی قابل استفاده‌اند.

## مدل ریاضی و توابع تبدیل

مدل فرآیند:

\[
G(s)=\frac{1}{\tau s+1}
\]

کنترل‌کننده تناسبی و حلقه باز:

\[
C(s)=K_p,\qquad L(s)=C(s)G(s)=\frac{K_p}{\tau s+1}
\]

با فیدبک منفی واحد، تابع تبدیل حلقه‌بسته از مرجع به خروجی:

\[
T(s)=\frac{Y(s)}{R(s)}=\frac{L(s)}{1+L(s)}
=\frac{K_p}{\tau s+1+K_p}
\]

تابع حساسیت (از مرجع به خطای تعقیب):

\[
S(s)=\frac{E(s)}{R(s)}=\frac{1}{1+L(s)}
=\frac{\tau s+1}{\tau s+1+K_p}
\]

تابع تبدیل فرمان کنترل به مرجع:

\[
\frac{U(s)}{R(s)}=\frac{C(s)}{1+C(s)G(s)}
=\frac{K_p(\tau s+1)}{\tau s+1+K_p}
\]

## مشخصات تحلیلی سیستم

برای ورودی پله واحد و \(K_p>0\):

- بهره DC حلقه‌بسته: \(K_{DC}=\frac{K_p}{1+K_p}\)
- خطای ماندگار: \(e_{ss}=\frac{1}{1+K_p}\)
- ثابت زمانی حلقه‌بسته: \(\tau_{cl}=\frac{\tau}{1+K_p}\)
- قطب حلقه‌بسته: \(p=-\frac{1+K_p}{\tau}\)
- زمان خیز ۱۰ تا ۹۰ درصد: \(t_r=\ln(9)\tau_{cl}\)
- زمان نشست با معیار ۲ درصد: \(t_s\approx-\ln(0.02)\tau_{cl}\approx3.912\tau_{cl}\)
- اضافه‌جهش نظری: صفر؛ پاسخ مدل مرتبه اول یکنواخت است.
- پایداری: برای \(\tau>0\) و \(K_p>0\)، قطب منفی و سیستم پایدار است.

## فایل‌ها و خروجی‌ها

- `README.md`: معرفی پروژه، روابط ریاضی و راهنمای اجرا

1. پاسخ پله فرآیند بدون کنترل
2. مقایسه پاسخ پله حلقه‌بسته برای مقادیر مختلف \(K_p\)
3. پاسخ خطای تعقیب
4. سیگنال کنترلی
5. نمودار بود حلقه باز و حلقه‌بسته
6. نقشه قطب‌ها و صفرهای حلقه‌بسته
